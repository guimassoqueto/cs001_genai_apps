# Langchain Core Concepts

LangChain, an open-source interface that simplifies building applications using large language models (LLMs).

LangChain Language and Chat Models
* Language models take text input and generate text output, supporting tasks like summarization and content generation.
* Chat models are specialized for conversational interactions, handling different message types such as human, AI, system, function, and tool messages.

Prompt Templates and Example Selectors
* Prompt templates convert user inputs into clear instructions for the language model, with types including string prompts and chat prompts.
* Example selectors help choose relevant examples to include in prompts, improving the model's contextual understanding and output quality.

Output Parsers
* Output parsers transform raw LLM outputs into structured formats like JSON, CSV, or data frames.
* This enables easier data handling and integration with other applications or analysis tools.
